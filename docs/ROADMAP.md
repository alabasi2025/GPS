# ROADMAP — القيود المعروفة والتحسينات الممكنة

## قيود حالية
1. **لم يُختبر على جهاز حقيقي** (انظر `docs/TESTING.md` §5).
2. PDR يفترض الجوال في اليد أمام المستخدم؛ في الجيب/التأرجح يضعف الاتجاه.
3. لا يعمل التتبع بالخلفية (لا Foreground Service) — عند إغلاق الشاشة قد يتوقف البث.
4. وضع `sensors` يتراكم خطؤه (~2–5٪ من المسافة في المحاكاة).
5. لا يوجد كشف للصعود/النزول (باروميتر) ولا للطوابق.
6. عتبات كشف الخطوة ثابتة (1.0 m/s²، 0.3) وقد تحتاج ضبطاً حسب الجهاز.
7. الخريطة والعنوان يحتاجان إنترنت (OSM/Nominatim).
8. المحدّث يعتمد على GitHub API بدون توكن (حد 60 طلب/ساعة لكل IP — كافٍ).
9. مكتبة صغيرة `libdatastore_shared_counter.so` لمعماريات أخرى تأتي من `shared_preferences` (~18KB، غير مؤثرة).

## تحسينات مقترحة (بالأولوية)
1. **اختبار ميداني** وضبط العتبات بناءً على بيانات حقيقية (سجّل الحساسات إلى ملف CSV).
2. **ZUPT / كشف الوقوف**: صفّر النمو في التغاير عند السكون.
3. **معامل Weinberg تكيفي** حسب الإيقاع (Liu 2026: `K = θ0 + θᵀu` بميزات التردد/RMS).
4. **تصنيف وضعية الحمل** (يد/جيب/أذن) لتحسين الاتجاه.
5. **Foreground Service** للتتبع مع الشاشة مطفأة.
6. **GNSS raw measurements** (`GnssMeasurement`) + تصحيحات/ثنائي التردد L5 للأجهزة الداعمة.
7. **تصدير النقاط** GPX/KML/CSV.
8. **خرائط بدون إنترنت** (تخزين البلاطات).
9. اختبار Widget للشاشة الرئيسية مع محاكاة القناة الأصلية.
