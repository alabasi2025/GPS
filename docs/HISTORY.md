# HISTORY — سجل القرارات والمشاكل

## طلبات المالك بالترتيب الزمني
1. تطبيق بسيط سريع يحدد الموقع والعنوان ويشاركه (مثل واتساب) — **بدقة**.
2. "أنا قلت لك تطبيق" ⇒ يريد APK أندرويد، لا معاينة ويب فقط.
3. "45 ميقا؟" ⇒ تصغير + **64-بت فقط**.
4. "حل مشكلة الانقطاع وتأكد وانقص الحجم" ⇒ أداة إشعار البناء تنقطع؛ الحل روابط مباشرة.
5. رابط تحميل مباشر سريع.
6. شرح مختصر بكود بلوك لوكيل آخر.
7. رفع المشروع على المستودع وتوثيقه + رابط تحميل مباشر من GitHub.
8. الاعتماد على **GPS الهاتف** بدقة عالية جداً.
9. تثبيت أول دقيق (Google + GPS) ثم **حساسات الهاتف** (خطوات/اتجاه) + **لقطة صورة + نقطة** + بحث عن أحدث الخوارزميات + **زر تحديث تلقائي** من المستودع.
10. حفظ ملفات التثبيت/التوقيع/الهاش في المستودع للتحديث بدون حذف في الجلسات الجديدة.
11. **التوثيق الكامل داخل GitHub** بحيث يكفي أن يحلّله الوكيل القادم (هذه الوثائق).

## الإصدارات
### v1.0.0 (versionCode 1)
- Flutter + geolocator (Fused, `bestForNavigation`)، flutter_map/OSM، Nominatim، share_plus، url_launcher.
- R8 + shrinkResources + arm64 + obfuscate: **45MB → 16MB → 7.4MB**.
- إزالة `cupertino_icons`.
- توقيع release بمفتاح `release-key.jks` (الشهادة 4fc4240d…ae91) بدلاً من debug.

### v1.1.0 (versionCode 2)
- قراءة `GPS_PROVIDER` الخام أصلياً + `GnssStatus` (أقمار/أنظمة/C/N0).
- متوسط مرجّح بعكس التباين أثناء الثبات (حتى 60 قراءة). كشف Mock.

### v1.2.0 (versionCode 3) — الحالي
- **استُبدل** متوسط v1.1 بمحرك `FusionEngine` (Kalman ثنائي الأبعاد) في `lib/engine/fusion.dart`.
- المرحلة 1: Fused + GPS خام معاً، بوابة χ²، أرضية تغاير، منع العدّ المزدوج.
- المرحلة 2: PDR (كشف خطوات تكيفي، Weinberg، Google Fused Orientation + احتياطي Rotation Vector)، معايرة K والانحياز.
- تحديد نقطة / لقطة + نقطة، قائمة النقاط، مشاركة مع الصورة.
- المحدّث التلقائي (GitHub Releases + FileProvider + REQUEST_INSTALL_PACKAGES).
- رفض صلاحية "الموقع التقريبي".
- الحجم 8.6MB (زيادة بسبب image_picker/shared_preferences/play-services-location المباشرة).

## مشاكل واجهتها وحلولها
| المشكلة | السبب | الحل |
|---|---|---|
| أداة `flutter_build_completion_notifier` تنقطع | مشكلة في الأداة نفسها | روابط مباشرة (GitHub Releases) بدلاً منها |
| APK 45MB | 3 معماريات + بدون R8 | arm64 فقط + R8 + obfuscate + excludes |
| `Gradle build daemon disappeared` | `-Xmx8G` على جهاز 8GB | `-Xmx3G`, `workers.max=2` |
| أمر bash يُقتل | `pkill -f GradleDaemon` طابق الصدفة نفسها | تشغيل البناء بسكربت `setsid nohup` |
| تعارض أسماء `Step` | `flutter/material` فيها `Step` | تسمية `StepEvent` |
| تعارض `Path` | `latlong2` تصدّر `Path` | `import 'package:latlong2/latlong.dart' hide Path;` |
| GitHub secret غير ممكن | التوكن بدون صلاحية `secrets` (403) | كلمة السر عند المالك فقط؛ يمكنه إضافتها يدوياً كسرّ `SIGNING_PASS` |
| `gh` CLI غير متوفر | — | استخدام GitHub REST API عبر curl |

## قرارات تصميم
- **لماذا Kalman وليس متوسط بسيط؟** يدمج مصادر بدقات مختلفة بأوزان صحيحة، ويسمح بالتنبؤ بالخطوات بين القراءات،
  ويعطي تقدير دقة متّسق.
- **لماذا Weinberg؟** بسيط، قابل للتفسير، ومعتمد كأساس في الأدبيات الحديثة (Liu 2026)؛ المعامل K يتعاير من GPS.
- **لماذا Fused Orientation من Google؟** يعطي شمالاً حقيقياً وتقدير خطأ رسمي، أفضل من تكامل الجيروسكوب اليدوي.
- **لماذا وضعان؟** طلب المالك "بعدين يعتمد على مستشعرات الهاتف" ⇒ `sensors`؛ و `hybrid` افتراضي لأنه الأدق خارج المباني.
- **لماذا 68٪ ⇒ /1.515؟** تعريف `Location.getAccuracy()` في أندرويد.
- **لماذا تجاهل `cached`؟** آخر موقع معروف قد يكون قديماً بدقائق ويُفسد التثبيت.
